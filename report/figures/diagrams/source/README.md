# Diagram Sources

`TrustFin_Architecture.drawio` is the editable multi-page Draw.io source for the report diagrams. Open it in diagrams.net or the Draw.io extension and edit each named page.

| Draw.io page | Report export |
|---|---|
| System architecture | `../system_architecture.png` |
| Evaluation workflow | `../system_workflow.png` |
| Use cases | `../use_case_diagram.png` |
| API classes | `../class_diagram.png` |
| Sequence | `../sequence_diagram.png` |
| Component view | `../component_diagram.png` |
| Deployment | `../deployment_diagram.png` |
| Package map | `../package_diagram.png` |

`TrustFin_DataFlow.drawio` contains editable DFD Level 0 and Level 1 pages. `TrustFin_Methodology.drawio` contains the offline model lifecycle and runtime evaluation flow. These source-only diagrams have no PNG exports yet.

The use-case figure has an IEEE-style black-and-white SVG and 300 dpi PNG export in the parent folder. Other PNGs have not been re-exported after the spacing and accuracy updates. PlantUML files are retained as prior drafts; `original/` holds the supplied reference images.
