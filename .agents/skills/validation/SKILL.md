# Validation Skill

This is a strict research methodology skill.

Before implementing any validation metric (Faithfulness, Stability, Consistency, Fairness, or the composite Trust Score):

1. Define what property is being measured.
2. Provide mathematical formulation.
3. Explain the interpretation.
4. Explain limitations.
5. Identify relevant literature.
6. Compare reasonable alternatives.
7. **Wait for human approval.**

Never implement a metric merely because it produces a convenient number. The mathematical definition and interpretation must be approved by the project owner first.
